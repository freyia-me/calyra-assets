ФАВИКОНЫ CALYRA LUX 5

Знак: буква «C» шрифтом Prata, белая на винном фоне #651d2d.

Файлы
  favicon.ico                  — 16, 32 и 48 px в одном файле (для всех браузеров)
  favicon.svg                  — векторный значок для современных браузеров
  favicon-16x16.png, -32x32, -48x48 — вкладки браузера
  favicon-tilda-152.png        — для загрузки в настройки Тильды
  apple-touch-icon.png         — 180 px, иконка на экране iPhone и iPad
  android-chrome-192x192.png, -512x512 — Android и закладки
  maskable-512x512.png         — Android, значок с запасом под обрезку
  mstile-150x150.png           — плитка Windows
  site.webmanifest             — описание значков для Android
  head-code.txt                — код для вставки в <head>

Как подключить в Тильде
  1. Настройки сайта → Главное (или «Ещё») → «Иконка сайта» (favicon):
     загрузите favicon.ico. Если Тильда просит PNG — favicon-tilda-152.png.
  2. Для иконок iPhone и Android: Настройки сайта → Ещё →
     «HTML-код для вставки внутрь head» — вставьте содержимое head-code.txt.
  3. Сохраните и переопубликуйте все страницы.
  4. Браузеры долго помнят старый значок: проверяйте в режиме инкогнито.
