# Revolution Bio: переезд с Joomla на Tilda

Страницы сайта revolution.bio, перенесённые в блоки T123 («HTML-код») для Tilda.
Старый сайт продолжает работать, пока вы собираете новый.

## Что внутри

| Папка / файл | Что это |
|---|---|
| `tilda/*.html` | 14 страниц. Каждая вставляется целиком в один блок T123 |
| `tilda-txt/*.txt` | То же самое в формате .txt, удобно открыть и скопировать с телефона |
| `img/` | Фото с сайта, уменьшенные и сжатые (WebP). Подгружаются автоматически через jsDelivr |
| `redirects.txt` | 301-редиректы со старых адресов на новые, чтобы не потерять позиции в поиске |
| `seo-pages.txt` | Title, Description и Keywords для каждой страницы |
| `data/jeuderm-products.json` | Товары JeuDérm (с сайта jeuderm-russia.ru): названия, фото, состав, применение |
| `data/rejusome-products.json` | Товары Rejusome (с сайта rejusome.com): названия, фото, состав, показания, курс |
| `source/photo-*.webp` | Оригинальные фото продукции (Rejusome Plus, Exo Boost Cream, Serum, Eye Cream, Lip Balm) — в карточках и окнах товаров |
| `tools/gen.py` | Скрипт, которым собраны страницы (для повторной сборки) |

Что убрано при переносе: рекламный вирусный скрипт `highperformanceformat.com`
(был в конце каждой страницы), весь код Joomla/K2, jQuery/MooTools,
старый Google Analytics, формы SendPulse.

## Как собрать сайт в Tilda

### 1. Страницы
Для каждого файла из `tilda/` создайте в Tilda пустую страницу:
1. **Создать страницу** → пустая страница.
2. **Настройки страницы → Главное → Адрес страницы**: адрес указан в первой строке файла
   (например, `rejusome` для `tilda/rejusome.html`). Для `home.html` отметьте страницу
   как главную в настройках сайта.
3. Добавьте блок **Другое → T123 «HTML-код»**, нажмите **Контент** и вставьте файл целиком.
4. **Настройки страницы → SEO**: заполните из `seo-pages.txt`.
5. **Опубликовать**.

Шапка, меню и подвал уже встроены в каждую страницу, отдельные блоки меню не нужны.

### 2. Формы заявок (обязательно)
Кнопки на страницах открывают всплывающие формы Тильды. На **каждой** странице, где они нужны,
добавьте блок **Форма → BF502N «Форма в попапе»** и в его настройках укажите ссылку:

| Ссылка на попап | Где используется | Поля |
|---|---|---|
| `#popup:callback` | «Заказать звонок», «Получить консультацию», «Стать моделью/тренером» | Имя, Телефон |
| `#popup:price` | «Узнать цену» на всех страницах и в окне товара | Имя, Телефон, E-mail, «Вы являетесь» (косметолог / клиника / пациент) |
| `#popup:partner` | «Узнать условия», «Получить прайс» на странице «Стать дистрибьютором» | Имя, Телефон, E-mail, Регион |
| `#popup:feedback` | «Обратная связь», «Написать нам», «Оставить заявку» | Имя, Телефон, E-mail, Сообщение |
| `#popup:signup` | «Записаться», «Записаться на обучение» на странице «Косметологам» | Имя, Телефон, E-mail |

Проще всего сделать формы один раз на главной, а потом скопировать блоки на другие страницы
(в меню блока «Копировать» → «Вставить» на другой странице).
В каждой форме включите галочку согласия со ссылкой на `/policy`,
а заявки направьте на почту `info@revolution.bio` (**Настройки сайта → Формы**).

### 3. Настройки сайта
- **Аналитика**: впишите номер Яндекс.Метрики (на старом сайте стояли счётчики
  `64807090` и `67546600`; оставьте тот, которым пользуетесь).
- **Ещё → Редиректы**: внесите строки из `redirects.txt` (старый адрес → новый).
- **Ещё → Уведомление о cookie**: включите (на старом сайте было своё окно).
- **Иконка сайта (favicon)**: загрузите логотип.

### 4. Переключение домена (сайт не «падает»)
1. Соберите и проверьте все страницы на техническом адресе Tilda (`project….tilda.ws`).
2. В Tilda: **Настройки сайта → Домен** укажите `revolution.bio`. Tilda покажет нужные DNS-записи.
3. В личном кабинете nic.ru: **DNS-хостинг** → замените A-запись (и CNAME для `www`) на значения из Tilda.
4. Переключение занимает от нескольких часов до суток. Всё это время сайт открывается (старый или новый).
5. После проверки нового сайта отключите хостинг Joomla на nic.ru.

## Структура сайта

**Меню:** Главная · Препараты ▾ (JeuDérm, Rejusome, Calyra Lux 5, Crystal PDRN) · Для профессионалов ▾
(Косметологам, Обучение и вебинары, Стать дистрибьютором) · Для пациентов · О компании ▾ (Революшн Био,
Производитель, Контакты). Выпадающие списки — стеклянные панели в стиле «голограмм» с первого экрана;
открываются при наведении или по клику, закрываются кликом мимо или Esc. На телефоне — раскрывающиеся
группы в кнопке «Меню». Структура меню — `MENU` в `tools/gen.py`.

| Адрес | Страница |
|---|---|
| `/` | Главная: первый экран с брендами, преимущества, карточки направлений, блок «Косметологам», пациенты и партнёры, о компании, контакты |
| `/jeuderm` | Все товары JeuDérm (Crystal PDRN — на своей странице). Фильтры «Уход» (профессиональный / домашний) и «Линейка» |
| `/rejusome` | 8 товаров Rejusome. Фильтр «Направление»: стерильные сыворотки / экзосомный уход / трихология. В окне товара — ссылка на подробную страницу rejusome.com |
| `/calyra-lux-5` | Calyra Lux 5: состав, действие, протоколы |
| `/crystal-pdrn` | Crystal PDRN: фото и видео, что такое PDRN, состав, преимущества, показания и противопоказания, схема курса, фото «до/после» (по презентации компании) |

| `/kontakty`, `/404`, `/policy`, `/soglasie` | Контакты, страница ошибки, документы |

**Как работают товары.** Отдельных страниц под товары нет. На странице бренда по клику на карточку
открывается окно товара — как на сайте JeuDérm: фото, описание, состав, применение, кнопки
«Узнать цену» и «Задать вопрос». У каждого товара свой адрес вида `/rejusome#p-rejusome-plus`,
а у фильтров — `/jeuderm?care=home&line=acno`. Такие ссылки можно давать клиентам и в соцсетях.

**Старые адреса не пропадут.** В `redirects.txt` — 146 переадресаций: страница старого товара ведёт
на страницу бренда и сразу открывает его окно (например, `/product/item/227-rejusome` →
`/rejusome#p-rejusome`), категории — на бренд с нужным фильтром, учебный центр и акции — на
«Косметологам», партнёры — на «Стать дистрибьютором».

**404.** В Tilda: Настройки сайта → Ещё → Страница 404 → выберите страницу `/404`.

**Ближайшие вебинары** на странице «Косметологам» — список `UPCOMING` в `tools/gen.py`.
Обновляйте его перед каждым вебинаром (или поправьте текст прямо в блоке T123).

**Фото товаров JeuDérm и Rejusome и письмо производителя** подгружаются из того же хранилища, что и сайты
jeuderm-russia.ru и rejusome.com, — отдельно загружать их не нужно.

## Что стоит проверить вручную
- **Новость «Экзосомы: крошечные переносчики…» (`/news-ekzosomy`)**: на старом сайте это
  перепечатка чужой статьи. Перенесено только ваше вступление. Если у вас есть право на
  публикацию полного текста, добавьте его сами или поставьте ссылку на первоисточник.
- **Расписание учебного центра**: даты взяты как есть (например, «01.02.2023»). Обновите
  неактуальные.
- **Соцсети**: ссылки взяты со старого сайта как есть. В подвале Telegram ведёт на
  `t.me/revolutionbio`, а на странице контактов на `t.me/revolution_bio`. Так было и раньше,
  проверьте, какой адрес правильный.

## Первый экран главной
Композиция: слева карточки брендов, в центре лицо, справа заголовок «Инновационные решения
для косметологов» и кнопки «Узнать цену» (`#popup:price`) и «Каталог продукции».

- **Четыре кадра — по одному на бренд** (JeuDérm, Rejusome, Calyra Lux 5, Crystal PDRN),
  сменяются каждые 6 секунд. Лица выровнены по размеру (`source/face-a…d.webp`).
- **Карточки брендов раскрываются аккордеоном**, как на сайте JeuDérm: у активной карточки
  открывается описание и ссылка «Подробнее», кнопка «+» превращается в «−». Наведение или
  клик на карточку переключает кадр.
- **От карточек к маске на лице идут тонкие голубые линии** с бегущим импульсом; у активного
  бренда по линии идёт «разряд».
- **Пульсирующие точки на лице**: при наведении (или по кругу автоматически) у точки
  появляется «голограмма» — иконка, технология бренда и его преимущества.
- Под лицом — название препарата контурными буквами.
- На телефоне: лицо, под ним название и преимущества строкой, затем текст и карточки-аккордеон;
  линии и голограммы скрыты.
- **Полоса преимуществ** под первым экраном: 100% оригинальная продукция · Официальный
  дистрибьютор в России · 15 000 клиентов в нашей базе · Поддержка и обучение специалистов.
- Шапка при прокрутке больше не меняет высоту, параллакс и «наезд» на фото убраны —
  экран не дёргается.

Тексты: `BRANDS`, `BRAND_DESC`, `HERO_SLIDES` (подписи-преимущества), `TRUST` в `tools/gen.py`.

## Каталог
**Главная** — «гармошка» из шести карточек-постеров (`source/card-*.webp`), как на сайте JeuDérm:
открытая карточка видна целиком с кнопкой «Подробнее», остальные узкие, приглушённые, с подписью.
На компьютере карточка раскрывается при наведении, на телефоне — по нажатию (столбиком).
JeuDérm PDRN → `/jeuderm?line=pdrn`, Стерильные сыворотки → `/rejusome?type=serum`,
Теломерная защита → `/calyra-lux-5`, Экзосомный уход → `/rejusome?type=cosmetics`,
Трихология → `/rejusome?type=hair`, Пептидная космецевтика JeuDérm → `/jeuderm`.
Карточки — `PRODUCT_CARDS`, подписи и цвета панелей — `CARD_TABS` в `tools/gen.py`.

**Страница JeuDérm** — блок «Уход по задачам кожи»: вертикальные панели-«шторки» с фото линеек
(Reform Age, Acno Active, Ato Care, Hair Genesis, Nova · Zymo, ПРО-уход, Crystal PDRN).
Активная панель раскрывается в цвете с описанием; «Смотреть средства» переключает фильтр
каталога ниже на этой же странице и прокручивает к нему. На компьютере панель раскрывается при
наведении, на телефоне — по нажатию. Фото — `source/panel-*.webp`, тексты — `CATALOG_PANELS`.

## Круглые картинки-«пузыри»
`source/round-*.webp` стоят в карточках брендов на первом экране главной и в шапках страниц
JeuDérm, Rejusome и Calyra Lux 5.

## Что убрано по сравнению со старым сайтом
- Страница «Партнёры» и все ссылки на неё: единственный партнёр теперь JeuDérm, старые
  адреса партнёров перенаправляются на страницу JeuDérm (см. `redirects.txt`).
- Всё про MINT Lift: две новости и отзыв о вебинаре по нитям. Старые адреса новостей
  перенаправляются на список новостей.
- Логотипы бывших партнёров на главной.
- Отзывы, новости, акции, учебный центр и отдельные страницы товаров и категорий — их содержание
  перенесено на страницы брендов и «Косметологам», старые адреса переадресуются.
