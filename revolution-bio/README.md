# Revolution Bio: переезд с Joomla на Tilda

Страницы сайта revolution.bio, перенесённые в блоки T123 («HTML-код») для Tilda.
Старый сайт продолжает работать, пока вы собираете новый.

## Что внутри

| Папка / файл | Что это |
|---|---|
| `tilda/*.html` | 32 страницы. Каждая вставляется целиком в один блок T123 |
| `tilda-txt/*.txt` | То же самое в формате .txt, удобно открыть и скопировать с телефона |
| `img/` | Фото с сайта, уменьшенные и сжатые (WebP). Подгружаются автоматически через jsDelivr |
| `redirects.txt` | 301-редиректы со старых адресов на новые, чтобы не потерять позиции в поиске |
| `seo-pages.txt` | Title, Description и Keywords для каждой страницы (взяты со старого сайта) |
| `tools/gen.py` | Скрипт, которым собраны страницы (для повторной сборки) |

Что убрано при переносе: рекламный вирусный скрипт `highperformanceformat.com`
(был в конце каждой страницы), весь код Joomla/K2, jQuery/MooTools,
старый Google Analytics, формы SendPulse.

## Как собрать сайт в Tilda

### 1. Страницы
Для каждого файла из `tilda/` создайте в Tilda пустую страницу:
1. **Создать страницу** → пустая страница.
2. **Настройки страницы → Главное → Адрес страницы**: адрес указан в первой строке файла
   (например, `rejusome` для `tilda/rejusome.html`). Для `home.html` отметьте страницу
   как главную в настройках сайта.
3. Добавьте блок **Другое → T123 «HTML-код»**, нажмите **Контент** и вставьте файл целиком.
4. **Настройки страницы → SEO**: заполните из `seo-pages.txt`.
5. **Опубликовать**.

Шапка, меню и подвал уже встроены в каждую страницу, отдельные блоки меню не нужны.

### 2. Формы заявок (обязательно)
Кнопки на страницах открывают всплывающие формы Тильды. На **каждой** странице, где они нужны,
добавьте блок **Форма → BF502N «Форма в попапе»** и в его настройках укажите ссылку:

| Ссылка на попап | Где используется | Поля |
|---|---|---|
| `#popup:callback` | «Заказать звонок», «Получить консультацию», «Стать моделью/тренером», «Начать бизнес» | Имя, Телефон |
| `#popup:feedback` | «Обратная связь», «Написать нам», «Оставить заявку» | Имя, Телефон, E-mail, Сообщение |
| `#popup:order` | «Заказать товар» на страницах товаров | Имя, Телефон, E-mail |
| `#popup:signup` | «Записаться» в учебном центре | Имя, Телефон, E-mail |
| `#popup:discount` | «Получить скидку» на странице акций | Имя, Телефон, E-mail |

Проще всего сделать формы один раз на главной, а потом скопировать блоки на другие страницы
(в меню блока «Копировать» → «Вставить» на другой странице).
В каждой форме включите галочку согласия со ссылкой на `/policy`,
а заявки направьте на почту `info@revolution.bio` (**Настройки сайта → Формы**).

### 3. Настройки сайта
- **Аналитика**: впишите номер Яндекс.Метрики (на старом сайте стояли счётчики
  `64807090` и `67546600`; оставьте тот, которым пользуетесь).
- **Ещё → Редиректы**: внесите строки из `redirects.txt` (старый адрес → новый).
- **Ещё → Уведомление о cookie**: включите (на старом сайте было своё окно).
- **Иконка сайта (favicon)**: загрузите логотип.

### 4. Переключение домена (сайт не «падает»)
1. Соберите и проверьте все страницы на техническом адресе Tilda (`project….tilda.ws`).
2. В Tilda: **Настройки сайта → Домен** укажите `revolution.bio`. Tilda покажет нужные DNS-записи.
3. В личном кабинете nic.ru: **DNS-хостинг** → замените A-запись (и CNAME для `www`) на значения из Tilda.
4. Переключение занимает от нескольких часов до суток. Всё это время сайт открывается (старый или новый).
5. После проверки нового сайта отключите хостинг Joomla на nic.ru.

## Что стоит проверить вручную
- **Новость «Экзосомы: крошечные переносчики…» (`/news-ekzosomy`)**: на старом сайте это
  перепечатка чужой статьи. Перенесено только ваше вступление. Если у вас есть право на
  публикацию полного текста, добавьте его сами или поставьте ссылку на первоисточник.
- **Расписание учебного центра**: даты взяты как есть (например, «01.02.2023»). Обновите
  неактуальные.
- **Соцсети**: ссылки взяты со старого сайта как есть. В подвале Telegram ведёт на
  `t.me/revolutionbio`, а на странице контактов на `t.me/revolution_bio`. Так было и раньше,
  проверьте, какой адрес правильный.

## Первый экран главной: портреты и бренды
Портреты сменяются автоматически каждые 5 секунд, на каждом кадре плашка с брендом и фразой
(ссылка ведёт на страницу бренда). Под первым экраном бегущая строка с брендами.
При наведении мышью смена кадров останавливается. Если на устройстве включено
«уменьшение движения», слайдер не листается сам.

Чтобы добавить или заменить кадр:
1. Положите фото с прозрачным фоном в `source/` (например, `source/hero-7.webp`).
   Лучше пропорции 4:5, как у остальных (1122×1402).
2. В `tools/gen.py` допишите строку в список `HERO_SLIDES`: файл, бренд, фраза, ссылка.
   Слова бегущей строки — в списке `MARQUEE` там же.
3. Пересоберите страницы скриптом и замените код главной в Tilda.
