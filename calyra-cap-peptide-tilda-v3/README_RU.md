# Страница CAP Пептида 5 для Tilda

Готовый адаптивный блок для страницы **«CAP Пептид 5 и теломерная защита кожи»**. Меню и подвал в код не входят — они остаются отдельными блоками Tilda.

## Что находится в пакете

- `CALYRA_CAP_PEPTIDE_T123_v3.html` — полный код для блока T123;
- `CALYRA_CAP_PEPTIDE_T123_v3.txt` — тот же код в текстовом формате;
- `preview_local.html` — локальный предпросмотр с изображениями из папки `assets`;
- `assets/` — две PNG-графики, которые нужно загрузить в GitHub;
- `ASSETS_MANIFEST.txt` — готовые публичные адреса файлов.

## 1. Загрузите изображения в GitHub

Откройте репозиторий `freyia-me/calyra-assets` и загрузите содержимое папки `assets` в существующую папку репозитория с тем же названием:

```text
calyra-assets/
└── assets/
    ├── CALYRA_LUX_CAP_Peptide_5_telomeres_transparent_v3.png
    └── CALYRA_LUX_syringe_apple_style_no_background_v3_full.png
```

Сохраните изменения кнопкой **Commit changes**. После обновления GitHub Pages проверьте, что оба адреса из `ASSETS_MANIFEST.txt` открывают изображения в браузере.

## 2. Вставьте код в Tilda

1. Откройте страницу про пептид.
2. Добавьте блок **T123 — HTML-код**.
3. Откройте `CALYRA_CAP_PEPTIDE_T123_v3.html`.
4. Скопируйте содержимое целиком, начиная с комментария и заканчивая `</script>`.
5. Вставьте код в T123, сохраните и опубликуйте страницу.

Код уже содержит абсолютные ссылки на GitHub Pages. После загрузки PNG менять адреса вручную не нужно.

## 3. Кнопки и popup

Первая кнопка прокручивает страницу к разделу с объяснением механизма.

Финальная кнопка сейчас ведёт на:

```text
/technology-calyra-lux-5
```

Чтобы открыть popup Tilda, замените только значение `href` у финальной кнопки. Например:

```html
href="#popup:calyra-contact"
```

В настройках popup-блока Tilda укажите такую же ссылку: `#popup:calyra-contact`.

## Адаптивность

В коде предусмотрены версии для:

- десктопа от 1100 px;
- планшетов до 820 px;
- мобильных экранов до 520 px.

Шприц расположен внутри финальной карточки и не должен перекрывать текст. Карточки блока из пяти направлений имеют единый размер и отступы на десктопе, а на мобильном становятся последовательным вертикальным списком.

## Шрифты

- заголовки: `Prata`;
- основной текст: `Manrope`.

Они подключаются в начале кода через Google Fonts.

## Если Tilda кэширует старую версию

Опубликуйте страницу повторно и откройте её в режиме инкогнито. Если заменили PNG, но сохранили имя файла, добавьте к адресу изображения параметр версии, например `?v=4`.
